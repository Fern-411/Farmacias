6.2. COMPARACIÓN EXHAUSTIVA ENTRE LAS ALTERNATIVAS

Criterio Evaluado Alternativa 1 (Elegida): Microservicios Spring + React Alternativa 2: Monolito Java EE / JSF Alternativa 3: ERP Cloud + Middleware Java
Uso de TIC Java 70% Java (Spring Boot, Spring Cloud, JPA) 90% Java (Java EE, EJB, JSF, Servlets) 50% Java (Middleware JMS/Camel)
Escalabilidad Alta: Escalado horizontal elástico por servicio. Baja: Escalado vertical costoso. Media: Restricciones de concurrencia ERP.
Resiliencia a Fallos Alta: Si falla Alertas, Consultas sigue operando. Nula: Caída del monolito paraliza la red. Alta en ERP / Media en enlace.
Experiencia de Usuario (UX) Excelente: Asíncrona, ágil y reactiva (SPA). Básica: Recargas completas de página síncronas. Compleja: Formularios ERP poco amigables.
Costo de Licenciamiento S/ 0 (100% Open Source): Sin pagos por usuario. S/ 0 (Open Source). Muy Alto (Inviable): Licencias para >2,500 QF.
Factibilidad Técnica ALTA: Estándar de la industria para retail. MEDIA / BAJA: Considerada deuda técnica. MEDIA: Dependencia de APIs propietarias.
Factibilidad Económica ALTA: Máximo retorno de inversión (ROI). MEDIA: Alto costo de mantenimiento. BAJA: TCO prohibitivo.

6.3. SELECCIÓN Y JUSTIFICACIÓN DE LA ALTERNATIVA MÁS VIABLE

Se selecciona concluyentemente la Alternativa 1 (Arquitectura de Microservicios con Java Spring Boot y React) debido a que:

  1. Soporte de Alta Concurrencia: Procesa más de 350 transacciones por segundo (TPS) distribuidas en >2,200 locales sin riesgo de bloqueo monolítico.
  2. Viabilidad Financiera: Al basarse en software libre (Spring Boot, PostgreSQL, React), ahorra cientos de miles de dólares en licencias comerciales por usuario.
  3. Algoritmo Predictivo a Medida: Otorga flexibilidad total para calcular la distancia de Haversine (< 10 km) y el semáforo FEFO a 90, 60 y 30 días, garantizando el cumplimiento de la meta de reducir en un 22% las pérdidas económicas por mermas.
  4. Restricción Académica UTP: Cumple holgadamente con el requisito de emplear más del 50% de desarrollo en tecnología Java (70%).
